## копирование с github
в первую очередь надо установить сам git на твой комп с https://git-scm.com/install/
там по идее должно получиться скачать и в меню пуск в поиске можешь увидеть приложение Git Bash с такой разноцветной иконкой

### важно
достаточно распространенная ошибка, git bash и visual studio code должны быть установленны на одном диске, может быть D, может быть C, главное что на одинаковом
в случае чего так же win + shift + s и вперед в нейронку, исправлять ошибки :)

В первую очередь тебе надо бы создать одну глобальную папку в которой будут все проекты на vscode
у меня это допустим
```
D:\vscodeprojects
```
открываешь vs code, нажимаешь на ctrl + ` 
У тебя должна открыться консолька снизу
в ней тебе нужно перейти в твою папку которую ты создала ранее
для того чтобы это сделать ты пишешь в консоли
```
cd 
```
а тут вводишь твой путь до этой самой папки и еще, одной командой ты это не сделаешь, одно движение по папкам = одна команда cd.
Вот допустим у меня та папка находится в D:/program/projects/vscodeprojects
то и команды у меня будут:
```
cd program
cd projects
cd vscodeprojects
//ДОПОЛНИТЕЛЬНО что бы вернуться на один уровень назад нужно написать cd ..
```
после того как ты уверена что твой терминал находится в нужной папке ты пишешь:
```vs console
git clone https://github.com/Friendly2009/alpha_crm_open_source
```
у тебя должно скопироваться все в отдельную папку alpha_crm_open_source
Дальше можешь закрыть терминал. Нажимай в верхнем правом углу file -> openfolder
там высветиться типичная для винды окно с выбором папки
ты должна найти ту папку alpha_crm_open_source и нажать на select folder
дальше по идее у тебя справа появится менюшка со всеми файлами сайта.
## Запуск сайта
тут все интереснее
есть два основных метода запуска сайта, так то их больше и ты можешь пользоваться любым но я в основном этими двумя пользуюсь

### №1 node server.js
проще запустить но сложнее настраивать:
пишешь в консоль 
```
node server.js
```
появится сообщение что сервер запущен на такой то ссылке, переходиш по этой ссылке и вот твой сайт
В чем собственно проблема?
да в том что это запуск самого сайта со всеми его ссылками и функционалом
так просто переключаться между страничками не получится так как нужно настраивать их подключение через controller и routes, Нет, ну если смелая, вперед :) но хз хз
### №2 live server
В правой части экрана будет иконка с 4 квадратиками
Нажимаешь
в поисковике пишешь Live Server
качаешь и собственно всё
запустить его также просто
нажимаешь правой кнопкой мыши на нужный html файл в правой панельке, нажимаешь open with Live Server и по идее должен открыться браузер
Лично я рекомендую второй способ так как сервер это больше по моей части

в левой части экрана, третья по счету кнопка, такая интереская с тремя моедененными точками. Обрати на нее внимание
